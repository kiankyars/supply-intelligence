# Abilene gross-to-net operational rack demonstrator

Quarter: `2026-Q3`. As of: `2026-07-17`. Monte Carlo draws: `20,000`.

**This is an illustrative operational run. Site load, reservations, other-platform commitments, rack compatibility, target allocation, and commissioning inputs are synthetic. The output is not an estimate of actual Abilene headroom or rack deployments.**

Open `dashboard.html` first. `result.json` contains the complete model and lineage payload. `operational_outputs.csv` separates physical outputs from `input_estimates.csv`; `evidence_gaps.csv` ranks synthetic assumptions for replacement; and the two source JSON files preserve the hash-pinned scenario and gross-envelope inputs.
 `capacity_draws.csv` preserves every gross-to-net power and commissioning draw for downstream reconciliation without a quantile fit.
